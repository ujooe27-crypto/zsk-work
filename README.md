# 张书酷个人名片

这是一个适合部署到 GitHub Pages 的静态个人名片网站，主题围绕宠物医疗器械行业、产品咨询和合作联系。

## 文件说明

- `index.html`：网站首页
- `en.html`：英文版首页
- `styles.css`：全站样式
- `script.js`：移动端导航交互

## 使用方式

直接打开 `index.html` 可以预览网站。

如果要发布到 GitHub Pages：

1. 将这些文件上传到你的 GitHub 仓库。
2. 打开仓库的 `Settings`。
3. 进入 `Pages`。
4. 选择从 `main` 分支发布，目录选择 `/root`。
5. 保存后等待 GitHub 生成访问地址。
